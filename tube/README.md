# Meri Videos (میری ویڈیوز)

Apni YouTube videos aur playlists ki list jo iPhone ke home screen par app ki tarah chalti hai.
Videos YouTube ke official IFrame Player (youtube-nocookie.com) se chalti hain — YouTube ke
ads ya restrictions ko bypass nahi kiya gaya.

## Features
- YouTube link paste karein: `youtu.be`, `watch?v=`, `shorts/`, `live/`, aur playlist links
- Title aur thumbnail khud aa jate hain (YouTube oEmbed)
- Meri list, pasandeeda ★, haaliya (recent)
- Pichli / agli video, aur "khudkaar agli" (video khatam hone par agli chal jaye)
- Jo video bahar chalane ki ijazat na de, usay "YouTube mein kholein" se chalayein
- Light / dark mode, list isi phone mein save hoti hai

## iPhone par app banana
1. `tube/` folder ko kisi HTTPS host par deploy karein (maslan Netlify).
2. iPhone ke **Safari** mein woh link kholein.
3. Neeche **Share ⬆️** dabayein → **Add to Home Screen** → **Add**.

Ab home screen par "Videos" ka red icon aa jayega jo full-screen app ki tarah khulega.
